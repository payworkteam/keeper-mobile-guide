# KeeperAI Mobile UX Guide (Simplify 1.0)

지투시그마 키퍼AI **모바일** 프론트엔드 UX/UI 가이드 — 공개판.

**→ https://payworkteam.github.io/keeper-mobile-guide/**


## 정본과 이 저장소 (26/11/04)

- 회사 UI/UX 기준 정본은 [payworkteam/uiux-standards](https://github.com/payworkteam/uiux-standards)다. 이 가이드는 **uiux-standards v4.0.0**(커밋 `b755864`, 26/11/06)의 정함 카드를 **§8**에 옮긴 **읽는 판**이다(G-018: 지켜야 하는 기준은 정본 하나). 이 가이드와 정본이 다르면 정본을 따른다.
- 정본과 값이 달랐던 본문은 같은 날 고쳤다: 화면 좌우 20pt → 16pt(01-08 · C8), 통화 끝 카드 「AI로 요약받기」 → 「이 통화를 저장할까요? · 통화 저장하기 / 나중에」(06-02 · C9) — 모바일 편만 해당.
- 이 저장소는 26/11/04 `seinleepaywork`에서 `payworkteam`으로 옮겼다. 옛 주소는 새 주소로 넘어간다.
- 정본이 바뀌면 §8을 손으로 고치지 않고 다시 만든다(만든 방법: 정본 카드 md를 읽어 §8 HTML과 새김 원문 8절을 함께 생성).
- 웹 편: https://payworkteam.github.io/keeper-hqweb-guide/

## 무엇인가

소상공인 B2B 정산·운영 플랫폼의 화면 설계 규격이다. 개발자와 AI 코딩
에이전트(Claude Code)가 추측 없이 같은 결과를 내도록 만든 문서다.

- **§0 작업 개시 규칙** — 언제 이 문서를 펴고, 어떤 순서로 따르는가
- **§1 공통 헌법** — 무중단 피드백 · 모달 인풋 금지 · 점진적 정보 노출 · 타이포/금융 수치 · 서피스
- **§2 레이아웃 패턴** · **§3 거래 문서 상태 머신** · **§4 의도적 차이 vs 정리 후보**
- **§5 금지 패턴** — 작성 단계에 넣어야 하는 방어 코드
- **§6 Claude Code 룰셋** — `CLAUDE.md` 에 붙여넣는 정본
- **§7 미결 항목** · **자기준수 감사**

## 공개판 안내

이 저장소는 **공개판**이다. 사내 장애 이력의 발생 경위만 제외했고, 그 외는 전문과 같다.
**§7 미결 항목과 자기준수 감사 결과는 그대로 들어 있다.**

## 기술

단일 HTML 파일이고 **외부 요청이 0건**이다. 서체는 Spoqa Han Sans Neo(SIL OFL 1.1)를
문서에 등장하는 글자만 서브셋해 파일에 내장했다(웨이트 400/500/700).
라이트 테마 전용이다.
